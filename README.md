# One Line, One Laugh

A make.fun bounty entry: a Python program that writes a single hilarious line
of at most 200 characters to `entry.txt`.

## The entry

> I told my smart speaker a joke and it said, "I'm sorry, I didn't quite catch that" — which is exactly what my audience says.

## How to run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/one-line-laugh-coral-out python3 main.py
cat /tmp/one-line-laugh-coral-out/entry.txt
```
